# Alltag – fertige Builds

Hier liegen nur die fertigen Versionen von **Alltag**, Philipps persönlicher Tages-App. Der Code ist privat.

- **Android:** `Alltag.apk`
- **Windows:** `Alltag-Setup.exe`

Neueste Version: [Releases → Latest](https://github.com/plammerding/alltag-releases/releases/latest)

Die App meldet neue Versionen selbst („Version X.Y.Z ist da – Aktualisieren / Später“).
Ohne Freischaltung als Testnutzer im Google-Projekt kann sich die App nicht bei Google anmelden.
